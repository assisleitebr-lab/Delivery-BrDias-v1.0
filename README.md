# Delivery - Seu lanche do seu jeito

Base inicial responsiva em preto, laranja e vermelho, com Firebase Authentication e Cloud Firestore para cadastro, login e perfis.

## GitHub Pages
Envie todos os arquivos para um repositório e habilite Settings > Pages > Deploy from a branch > `main` > `/ (root)`.

## Firebase
Siga `firebase/README.md`. Ative Email/Password, crie Firestore, publique `firebase/firestore.rules`, configure Storage e publique `firebase/storage.rules`. A configuração do projeto Firebase informada já está em `js/config.js`.

**Atenção:** é uma base inicial, não um delivery pronto. Carrinho, checkout seguro, processamento de pedidos, gerenciamento de produtos/motoboys, atualizações de status e relatórios ainda precisam ser implementados e testados antes de uso comercial.
